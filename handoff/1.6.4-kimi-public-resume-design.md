# #222 Kimi durable resume 的公开上下文恢复

现状：store 明确剥离 reasoning，CLI 在 restore 前无条件拒绝含 assistant 的 Kimi snapshot；即使绕过 CLI，provider task-local 校验仍拒绝缺失官方 reasoning 的 assistant。不能放宽后一个校验，也不能把 private reasoning 落入通用 session、工具、摘要或日志。

采用 issue 允许的可恢复降级：保留 canonical session 和全部原始 ownership/closure/intent/digest 元数据，仅在 provider 请求视图中将恢复时已有的公开历史转换为现有 buildSynthesizedProviderContext 生成的 user 文本（40KB 上限，明确为合成上下文，不是 provider transcript）。CLI 显示可见恢复提示。当前 live 回合的官方 reasoning、tool use/result 必须原样保留；不能自动把新回合缺 reasoning 的 assistant 也转换掉。

Host 的 Agent.restoreSession 完成真实 restore 后，通知 runtime 从自己持有的 session 捕获恢复前缀长度、完整 digest 与 restore generation；不接收调用方前缀或资格对象。每次请求只在前缀和 generation 仍匹配时重建固定 provider 视图；前缀变化则失败关闭，若新历史本身已符合严格条件可清除恢复视图。活跃 compound intent stage 禁止合成，保留既有严格拒绝。

请求转换必须在 observationOwner.prepareRequest 前；原始 session 的 closure、所有权、执行租约和发布历史 digest 不变，owner 的 assertSession 和 provider disclosure 原路径继续执行。规范 durable messages 不被覆盖；重启可再次从同一持久化历史恢复。已有 fork 的存储闸门本版保留，不把 fork 偷换为复制。

CLI --resume/--continue/--takeover 的旧提前拒绝移除，转由上述 Host restore + 原始 provider gate 验证；--fork-session 保留原 guard。普通模型和无旧 assistant 的会话不变。新 live assistant 缺 reasoning 仍由原始 gate 拒绝。

回归先红：真实 Agent + 注册严格 Kimi adapter，恢复已剥离 reasoning 的 canonical 历史后发新输入；验证请求只有合成 user 前缀，旧工具调用不重放，当前工具回合原样，原 session 历史/closure 未变。补恢复前缀篡改、generation 更改、compound stage 拒绝、private canary 不进入合成文本、通用模型不变。CLI emitted 入口去除提前错误的 contract 与实际 resume 冒烟。独立模型先审设计，再写测试和实现。

保守资格：本次恢复只覆盖普通 CLI strict Kimi 历史。存在 protectedObservationClosure（含 requiresReauthorization 标记）、active compound stage 时不做公开合成，维持原始拒绝；不借此恢复 Native 受保护历史。Agent.restoreSession 自身的原始资源/observationOwner 守卫保持不变。初始化 initialSession 若不是经合法 restore 通知，不自动给缺 reasoning 的 live 历史恢复资格。

GLM 设计审查修正：恢复视图存在期间禁止会改写 canonical history 的跨 profile model-switch；普通同 profile 配置刷新可保留视图。前缀变化一律失败，不增加“看起来已严格”清除特例。session 的 restore listener 仅使旧恢复视图失效；由于通知发生在 graph restore 前，只有 Agent.restoreSession 成功返回后由 Host 显式捕获新前缀，不能在 listener 中提前捕获旧 graph，也不监听 graph revision（CAS installCommittedSnapshot 不算 restore）。

长历史：恢复视图活跃时，禁止跨 profile model-switch、手动 compact 以及自动/semantic compact 改写 canonical 历史；显式 clear/new session 仍可开始新会话。请求容量按合成 provider 视图 + 当前 live 尾部计，不用旧 snapshot usage 触发原始历史压缩；若 live 尾部达到当前模型 compact 阈值，明确拒绝并要求新会话，不无限发送超限请求。补大历史/高旧usage无压缩、跨 profile 变更先拒绝的回归。

## 最终验证

Codex 实现，GLM-5.3-Flash Free 两轮设计审查及最终代码审查：无可复现 P0/P1。实际 Agent 恢复/拒绝边界9/9、独立 CLI 子进程 --resume/--continue/--takeover 3/3；原 runtime/Agent/session-store/chat/builtin 合并回归174/174（当时新增7例，后扩为9例）。新恢复视图5例先红后绿，长历史与手动压缩2例也先红后绿。根 tsc、governance:check 通过；未验证真实外部 Kimi API，CLI fixture仅替换HTTP响应为SSE，实际启动/存储/授权/adapter路径均运行。恢复容量按总请求视图（合成前缀+live尾部+system/tools）与compact阈值比较，拒绝均抛可见错误，不能静默继续。

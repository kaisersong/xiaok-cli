# #243 fuse 发布依赖盘点

正式包尚未关闭 RunAsNode/NodeOptions/inspect。不能只改打包开关：下列已读取的生产入口仍使用 Electron executable 与 ELECTRON_RUN_AS_NODE。

- `src/runtime/context-continuity/profile-probe.ts:119`：同步隔离 census SQLite 子进程。
- `desktop/electron/activity-owner-writer-launch.ts:36`：原始 Main writer/dispatch 启动胶囊、子进程 birth/IPC relay；不是普通 broker 的可替换 runtime。
- `src/runtime/conversation-activity/owner-launcher.ts:66`：owner 启动与脱离生命周期。
- `desktop/electron/codex-native-transport.ts:64,150`：Codex transport。
- `desktop/electron/office-document-parser.ts:322`：office parser。
- `desktop/electron/desktop-services.ts:2047,7101`、`desktop/electron/room-external-discussion-adapter.ts:27`：运行时/外部讨论 adapter。
- `src/runtime/bundled-yzj-cli.ts:41`：内置 CLI 包装器。
- `desktop/scripts/verify-packaged-runtime-dependencies.cjs:70` 及多个 afterPack service gate 还通过 Electron Node 执行验证。

原始 Source/Native 启动与普通 broker 的 Node24 fallback 分属不同资格链，不能把带可执行路径/环境/transport 的 DTO 当新资格。此前 Electron43 候选也已因 ABI/资格不匹配退出本版。直接把全部子进程换成 Node24 不构成可验证的等价替换。

下一阶段方案应把受保护 children 移到 Main 独占、固定入口的 utilityProcess/独立已验证 Node host，保留原始 birth、IPC、生命周期、源绑定和 NoEscape；迁移完所有生产及验收消费者后再关闭三个 fuse，并对实际签名安装包读取 fuse 与做退回对照。此项若延期，明确列为已知限制，不将当前版本描述为已修复 #243。

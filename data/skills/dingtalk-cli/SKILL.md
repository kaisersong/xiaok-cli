# 钉钉 CLI

用户需要操作钉钉时使用 `dws`。如果命令不可用，引导用户打开 Desktop「设置 → 连接器 → 钉钉 → 下载安装」，然后扫码连接。不要自动安装、不运行远程安装脚本、不替用户扩大授权。

组织可能需要管理员先开通 CLI 访问。

1. 首次使用先运行 `dws --help`，再按意图查看对应子命令 `--help`，以实际 CLI 为准。
2. 查询优先；目标 ID 必须来自实际查询，不编造命令、账号或数据。
3. 写入、删除和发送消息遵循用户明确授权与当前工具权限；未获授权不发送消息，不取消/删除他人或用户任务。
4. 不输出 token、Secret、设备码、原始授权链接或凭证文件；登录问题引导到连接器中重试。
5. 权限不足时说明所缺能力，让用户在官方授权页确认，不自动重试更高权限。

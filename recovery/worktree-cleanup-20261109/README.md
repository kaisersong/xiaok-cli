# Worktree 源码恢复归档

本分支保存清理前的源码状态，供恢复与后续集成使用；没有改变可执行产品文件，不代表源码已合入主干或通过发布验收。

每个 tar.gz 包含 baseline/head、变更源码、删除列表、文件模式、原始与脱敏 SHA256，及存在时的暂存区源码。index.json 给出包摘要。恢复时从 baseline 建立 checkout，再按 manifest 覆盖 files（按 mode 还原符号链接）、执行 deleted，暂存区版本位于 index-files。

归档已逐文件读回校验；远端提交后还会下载 Git blob 重验 SHA256。Gitleaks 扫描通过：只认可经核实的 tokenizer 哈希、构造测试标识及远端已存在的本地 TLS 测试 fixture 误报；未扩大产品 ignore/baseline。

设备备份、私有配置、凭据、实验真实语料/运行结果、编译缓存与安装包未上传；它们保留在本机安全副本。真实本机用户路径已替换为合成路径；manifest 记录原始摘要，原始内容留在本机。

本仓归档 20 个快照、1582 个源码文件版本。仅执行恢复/摘要与凭据扫描；产品测试、构建、安装和发布未跑。

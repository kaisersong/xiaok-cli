# 提交后清理 worktree 的源码恢复资料

本次将本地分支提交及未提交源码保存到远端，再删除附属 worktree。主 checkout、本地分支、stash 与父级证据目录保留；不自动合并主干或发布。

本仓保存 25 个工作区源码快照，共 151 个源码文件版本。每包包含 baseline、变更源码、删除列表、文件模式和 SHA256；真实本机路径被替换为合成路径，原始内容及生成物另保留在本机安全副本。

恢复时从 baseline 建立 checkout，按 manifest 将 files 覆盖并恢复 mode/符号链接，应用 deleted；若有暂存版本则从 index-files 恢复。远端包会逐个下载，验摘要并在独立 Git index 重建源码树。此检查不是产品回归或发布验收；产品测试、构建、发布均未跑。

私有配置、凭据、设备备份、真实语料、运行结果和编译缓存不进入提交。未推送分支历史经 Gitleaks 检查；一个原生二进制 SHA256 常量误报已按精确来源核验，没有修改产品的 hook、ignore 或 baseline。

4 个原始候选头继承含私有数据的旧历史，因此不原样上传。它们的完整当前 Git tree 与公开历史候选4792806f83f8b09fcd12b3fac00723bb3242d4cb完全相同，四个source-equivalent远端引用保存该候选；原始提交/历史保留在本机 Git bundle 和原分支。

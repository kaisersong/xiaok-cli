# 旧本地目录源码恢复归档

本归档保存六份旧源码目录的清单，以及尚未对应到远端历史的 62 个源码文件，供清理旧套件目录后恢复使用。它不代表这些历史实现已经集成到当前主干或通过产品验收。

- `source-index.tar.gz`：完整源码路径、文件模式、Git blob 和 SHA-256 清单，及对应仓库的冻结远端 refs。
- `source-deltas.tar.gz`：62 个新增或独有源码文件，保留原有内容和可执行模式。
- 其余 3,681 个源码文件已存在于清单所列仓库的远端 Git 历史中，可按 blob ID 使用 `git cat-file blob <id>` 恢复，再对照 SHA-256。

恢复时先取得对应仓库的冻结 refs；将索引中的 `existing-remote-object` 文件从对应 Git blob 取回，将其余文件从源码包取回，按索引路径重建目录并校验哈希。

原始安装包、验证脚本、运行日志、隐藏本地状态与完整原始目录另外在本机压缩备份；依赖目录与可再生成缓存未重复保存到公共仓库。

验证：本地解包恢复 62/62 源文件并逐个校验 SHA-256，通过；源码包文本检查未发现本机身份路径、GitHub/API token 或实际私钥正文。业务回归、构建与跨平台打包未跑，本次仅归档历史文件。

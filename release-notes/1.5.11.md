# Xiaok CLI 1.5.11

> 草稿：等待创始人确认后发布。本版只发布 CLI（npm `xiaokcode` 与 `cli-v1.5.11` 标签），不发布 Desktop 安装包，不打 `desktop-v*` 标签。

## 更新 / Changes

- `~/.xiaok/config.json` 保存模型 API Key，现在只允许本人读写（权限 600）：读取时会尽量把老版本留下的宽松权限收紧；写入前如果收紧失败，会停止写入并提示检查文件所有者和权限，不会把 Key 写进别人可读的文件。**仅 Mac 和 Linux 生效，Windows 暂无此保护。**
- 新增“异步任务跟进”（交互式终端会话）：MCP 服务器以 MCP Tasks 方式执行的长任务，交给后台继续跟进，对话不再一直等待；任务有进展、需要你处理或结束时，在输入框空闲时显示一行 `[异步任务] 状态：摘要`。任务状态记录在本机，用 `--continue`/`--resume` 恢复同一会话后仍能收到未显示过的结果 [未核实：未在真实终端实测重启恢复]。
  - 为此 CLI 会在后台启动一个常驻的 Node 进程负责记录，数据存放在 `~/.xiaok/conversation-activity/` 下，按工作目录区分。退出 CLI 后这个进程不会自动结束（Linux 上直接调用启动逻辑实测确认；Mac、Windows 未实测）。
  - 不支持 MCP Tasks 的 MCP 服务器、`--print` 模式和非交互终端，行为与之前一致。设置环境变量 `XIAOK_CONVERSATION_ACTIVITY=0` 可关闭此功能。
- 提交后的输入在终端里用整行背景色绘制，窗口宽度变化时不会再多出空白行。
- 其余改动（会话文件字段顺序、内部任务结果格式）用户无感知。

## 已知问题 / Known issues

- **[阻断，待决定]** 新功能依赖 Node 内置的 `node:sqlite`。在 Node 22.0 到 22.12 上，CLI 启动即报错 `ERR_UNKNOWN_BUILTIN_MODULE: node:sqlite`，连 `xiaok --version` 都无法运行，而 `package.json` 声明的支持范围是 `node >=22`。1.5.10 在 Node 22.12.0 上能正常启动。发布前需要修复（例如按需加载，或把最低版本提高到 22.13）或在说明里写明最低 Node 版本。
  - 修复见 #23（按需加载 `node:sqlite`，加载不了就停用这项功能并提示一次）。#23 合并后，本说明会换成最终版。另外实测发现，Linux 上 Node 22.14.0 之前的版本打开交互会话会在 better-sqlite3 上段错误，1.5.10 同样如此，详见 #23。
- 在 Node 22.13 及以上的 22.x，交互会话会打印一次 `ExperimentalWarning: SQLite is an experimental feature`。Node 24 上是否同样出现 [未核实]。

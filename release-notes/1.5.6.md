# 1.5.6 · 2026-10-01

CLI 与 Desktop 版本统一为 1.5.6，关联服务使用 desktop-v1.5.6 固定标签。

## 中文

- 协作空间按最后消息活动倒序，分活跃／归档，显示最后活跃时间；“…”菜单可归档、确认删除，保留关联项目和本机文件。
- 修复浅色／深色按钮对比度，删除确认使用红底白字。
- CLI 与 Desktop 支持模型目录确认的思考强度，默认中间档并保留用户选择；未知模型、协议、代理和 custom provider 不额外传参。
- 中文 Markdown 表格对齐和窄窗字段展示，输出期间草稿保留，活动区间距优化；日志轮转和 transcript 输出大小限制。
- 加入成品运行依赖检查和 Ajv／cross-spawn 直接依赖，事务迁移旧多智能体 SQLite 索引；工作区路径恢复、CLI 更新 daemon 与 PTY／EPIPE 修复；工具 await 返回后立即核对取消，保留此前已完成结果。

## English

- Collaboration rooms have Active / Archived lists, last-active timestamp pills, activity ordering, and a “…” menu for archiving and confirmed deletion. Linked projects and local files are retained.
- Light/dark controls have readable contrast; destructive confirmation uses red and white.
- CLI and Desktop expose supported model reasoning tiers, default to the middle tier, retain valid saved choices and context limits, and propagate the chosen value to requests. Unsupported combinations do not acquire an effort parameter.
- Chinese Markdown tables align, narrow windows show labeled records, streaming preserves drafts, and activity spacing is clearer. Log rotation and a transcript-output cap bound runaway growth.
- Packaged runtime dependency validation includes Ajv/cross-spawn; SQLite index migration is transactional. Workspace recovery, daemon-safe CLI updates and PTY/EPIPE handling are improved. Tool cancellation is rechecked after await while retaining earlier completed results.

# Xiaok CLI & Desktop 1.5.9

## 更新 / Changes

- CLI 将 SubAgent / Thinking 清除和绘制合为完整终端帧，避免 120ms 多次写入导致闪烁；草稿和正文保留。
- CLI 图片读取向支持视觉的模型传递经过校验的图片；终端内嵌图片保留在对话历史里。
- Desktop 实时输出和历史回放按工具边界分段，减少重复结果；执行审批在聊天内展示，提供明确选择的本任务相同操作自动批准，参数变化、其他执行主体与新任务不继承。
- 模型连接中断恢复保留已执行工具结果；无正常结果的关闭提供可理解的说明。
- MCP tool events 转发调用进度。

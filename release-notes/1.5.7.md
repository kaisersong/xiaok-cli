# 1.5.7 · 2026-10-03

CLI 与 Desktop 版本统一为 1.5.7，关联服务使用 desktop-v1.5.7 固定标签。

## 中文

- `ask_user` 选项支持数字快捷键：直接输入序号即可选中对应选项，无需完整匹配文本。
- Windows Computer Use 落地：CUA host、win32 backend 与私有 release 安装共用同一 ABI profile；新增 `windows-cua-url` 归一化 URL，window observation 与 action contract 同步扩展。
- Windows 普通会话 bash 工具改为排空（drain）已退出子进程的输出流，避免写入未结束就读取造成缺失或误报；继承的 shell 输出会显式标记。
- Desktop 文件类 IPC 改为具名契约（`OpenFileResult`／`ReadFileResult`／`SaveFileInput`／`SaveFileResult`），main 进程按 schema 校验，preload 与 renderer 共用同一份类型。
- 治理门禁进入仓库：oxlint 与架构基线由 `scripts/governance/check.mjs` 统计“当前／新增”违规，新增 baseline 文件与 governance workflow。
- 文档集中：`ampliky`、`intent-broker`、`kai-business-blueprint`、`kswarm`、`xiaok-cli` 的 `docs` 统一为指向共享 `mydocs` 仓库的软链接（模式 `120000`）。

## English

- `ask_user` accepts numbered shortcuts, so a numeric answer selects the matching option without full-text matching.
- Windows Computer Use lands: the CUA host, win32 backend and private release install share one ABI profile; `windows-cua-url` normalizes URLs while window observation and the action contract grow together.
- The Windows ordinary-session bash tool drains an already-exited child's output streams, so partial writes no longer produce missing or false results; inherited shell output is marked explicitly.
- Desktop file IPC moves to a named contract (`OpenFileResult` / `ReadFileResult` / `SaveFileInput` / `SaveFileResult`) validated in main, with one shared type surface for preload and renderer.
- Governance gates land: oxlint plus the architecture baseline are counted as current/new violations by `scripts/governance/check.mjs`, with baseline files and a governance workflow.
- Documentation is centralized: `docs` in the five repositories becomes a symlink (`120000`) into the shared `mydocs` repository.

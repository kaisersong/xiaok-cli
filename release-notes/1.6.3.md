# Xiaok CLI & Desktop 1.6.3（发布候选）

本说明随集成候选维护；正式 tag、安装包和 npm 包尚未发布。

## Desktop

- 观测记忆设置统一通过聊天中的斜杠命令操作，移除消息输入区顶部的独立开关。
- 修复任务取消后，同一个协作成员的后续消息准备相互覆盖的问题；收尾继续等待已接纳的真实后台工作。
- 协作运行时就绪后自动刷新项目列表，旧请求的迟到结果不再覆盖新的状态。
- 后台服务使用 Desktop 实际选中的端口；显式请求的端口被占用时，子进程跟随本次实例选中的端口。
- 保留模型流失败和取消的原始原因，并完善迟到用量记账及独立资源收尾。

- 恢复助手定期分析、质量覆盖视图、建议分页与继续跟进入口；实际运行仍受当前授权及确认约束。
- 模型设置整合对话与辅助决策表单，记忆管理保留独立的向量与压缩模型选择；自动记忆重排未启用。
- 记忆压缩支持取消、调用前发送范围确认和失败重试；取消请求不会伪装成后台任务已结束。
- 切换向量模型会等待旧请求结束并清理旧缓存；增加受保护的本地模型文件删除与失败恢复。
- 修复空压缩结果消耗原始内容、项目记忆检索遗漏作用域的问题。

## CLI 与凭据

- 修复中文分词预热让空闲 CLI 进程无法自然退出的问题，保留等待中的分词结果。
- 原生凭据模块只从固定依赖包加载，拒绝环境变量指定任意 Native/WASI 模块。
- 加强凭据锁初始化期间的身份检查，保留凭据存储不可用时的明确拒绝。
- 修复最低支持 Node 版本在 Windows 上准备 SQLite 类型声明时的错误拒绝；文件身份比较保留完整整数精度。

## 范围与限制

- CLI 与 Desktop 正式发布时必须使用同一个完整提交 SHA；候选 SHA 和实际安装包复验记录在发布前填写。
- DSH 仍受现有生产资格门控制；未完成的原生系统验收不会因本次集成自动启用。
- Gemini 真实端点尚未完成独立验收。
- 本地大模型真实权重推理尚未完成本轮安装包验收；能力声明不代表质量认证。
- 非 Desktop 后代进程的服务发现仍有原发现机制限制；显式端口被占用时，Desktop 子进程已跟随实际所选端口。
- 私有文档 sibling 的 CI 读取凭据尚未配置；该外部权限阻塞仍保留。
- 最终分支覆盖、完整 HEAD 的质量结论、Windows 连续验证、实际 CI、正式安装包和 CLI tgz 复验未完成前，本候选不标为可发布。

# Xiaok CLI 与 Desktop 1.6.4

## 本版变化

- Desktop 关闭 Electron RunAsNode、NODE_OPTIONS 与 Node inspect 三个 fuse；后台 JavaScript 子进程使用固定、校验完整性的 Node 24.19.0，主进程继续从 app.asar 启动。

- Windows 旧配置通过系统 SID 与 ACL 检查后，可保留原会话作用域和授权，恢复列表及新会话发送；初始化使用独占锁和原子身份文件发布，不改写旧数据库来伪造迁移依据。
- 身份不可用时，不创建带临时假作用域的控制来源和后台授权。
- Windows 私有状态文件在创建时即限制访问，后台进程身份查询使用原生接口。手机网关默认仅监听本机，显式局域网共享仍可配置。
- 本机后台服务连接失败时提供中英文处理提示和诊断日志；超时后回收本次创建的进程及回执，释放占用端口。没有把系统网络策略或安全软件推断为已确认根因。
- Kimi 历史会话可通过公开上下文恢复：`--resume`、`--continue`、`--takeover` 保留最近 40KB 可见文字，原始持久化历史不变，旧工具操作不重放。新回合继续保留严格的 reasoning 协议校验。
- 修复设置中“测试连接”遇到旧明文凭据首次失败的问题；无关配置更新不再使当前模型会话失效。
- 修复终端选择器切换时回车丢失和 MCP 关闭等待；Linux 会话锁识别不再依赖 `/bin/ps`。
- 减少大量进度事件下的数据库扫描，保留终态同步和崩溃恢复规则。
- 合入工具管理入口与电脑操作组件下载/更新改进；助手遇到未知 mutation 回执时自动进行只读核对。
- 本轮 CLI 同时包含 1.6.3 已集成的凭据、启动与会话收尾修复。CLI 凭据默认存入私有文件（不宣称加密），可用 `xiaok config set credential-store keychain` 显式切换系统凭据存储。

## 支持范围与保留限制

- macOS 安装版最低为 13.5，低于此版本不再推送更新。本版保留 Electron 39.8.10。
- 缺少可靠执行结束证明的旧记录仍受限，删除可能保持待定；可使用新会话继续工作。历史清理单列后续修复，不把未知状态改成“已结束”。
- Kimi 恢复仅包含可见文字，不重放旧工具及图片；带受保护观测闭包或活跃 compound stage 的历史仍按原门禁拒绝。旧 Kimi 历史的 fork 门禁保留；恢复上下文达到容量上限时需开启新会话。
- Windows 本机通信的系统策略问题未宣称根治；本版提供诊断降级。服务不可用时，依赖它的功能仍可能暂不可用。
- 多用户行为评测与撤回/语言跟随、超过 1000 条定时任务、完整端口并存及 daemon 常驻体验按原计划熔断至 1.6.5，未标为已修复。
